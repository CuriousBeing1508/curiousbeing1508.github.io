We are investigating how large language models can be leveraged to automatically generate test cases that detect silent regressions and breaking API changes in software libraries.

**Research questions:**

- Can LLMs generate meaningful regression tests without prior knowledge of a library's internal implementation?
- How effective are LLM-generated tests at catching breaking changes before they reach downstream consumers?
- What prompting strategies and contextual signals best guide LLMs toward change-detecting test suites?
