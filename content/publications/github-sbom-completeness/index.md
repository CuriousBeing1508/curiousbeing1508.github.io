We conducted a large-scale empirical study of 10,000 GitHub repositories across ten programming ecosystems, evaluating GitHub's auto-generated SBOMs against three popular alternatives: Syft, Trivy, and the Microsoft SBOM Tool.

**Key findings:**

- GitHub's auto-generated SBOMs show gaps in NTIA minimum element compliance across several ecosystems.
- Version and license metadata availability varies significantly by ecosystem.
- GitHub performs comparably to Microsoft's SBOM Tool and often outperforms Syft and Trivy on completeness metrics.
