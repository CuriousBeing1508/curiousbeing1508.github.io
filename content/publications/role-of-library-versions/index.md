We analyzed 4,000+ Developer-ChatGPT interactions from the DevGPT dataset using a mixed-method approach to study how library version constraints are discussed in code-related conversations.

**Key findings:**

- 88.5% of library-related conversations omit version constraints entirely.
- This reveals a systematic gap in LLM-assisted development that poses real risks of breaking changes and dependency incompatibilities for developers relying on AI-generated code.
